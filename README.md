# Smart HR Email Automation & CV Management System

## Overview

The Smart HR Email Automation & CV Management System
automates job application emails and tracks application
activity through a custom dashboard.

The project uses Google Forms, Google Sheets, Google Drive,
Gmail, and Google Apps Script to simplify the application
email process.

## Features

- Automated email sending through Gmail
- CV selection based on the job role
- Automatic PDF attachment from Google Drive
- Google Sheets application tracking
- Email status tracking: Sent, Failed, and Processing
- Application history dashboard
- Company and date filters
- Search by company, HR email, or job role
- KPI cards for application statistics
- Dark-themed dashboard interface

## Technology Stack

- Google Forms
- Google Sheets
- Google Drive
- Gmail
- Google Apps Script
- HTML
- CSS
- JavaScript
- GitHub

## Workflow

1. Enter job application details through Google Forms.
2. Store submitted information in Google Sheets.
3. Process the submission using Google Apps Script.
4. Select the appropriate CV PDF from Google Drive.
5. Send the email through Gmail.
6. Record the email status in Google Sheets.
7. View application statistics in the dashboard.

## Project Structure

- `Dashboard.gs` - Dashboard backend
- `EmailAutomation.gs` - Email automation logic
- `Index.html` - Dashboard interface
- `Documentation/` - Project documentation
- `Screenshots/` - Dashboard screenshots

## Setup

1. Create a Google Form for job application details.
2. Link the form to a Google Sheets spreadsheet.
3. Upload CV templates to Google Drive.
4. Configure the Apps Script project.
5. Add the required CV PDF file IDs.
6. Configure the spreadsheet ID and sheet name.
7. Set up the form-submission trigger.
8. Deploy the dashboard as a web app.

## Security

Do not publish private CV files, HR contact records,
spreadsheet data, credentials, or authorization tokens.

Configure appropriate access permissions before deployment.
